# Manga Translator 2.0

漫画の文字領域を端末内で検出し、番号付きの切り抜き画像を選択したAIへ渡して翻訳・反映するChrome拡張機能です。

2.0は、ONNX Runtime版から **TensorFlow Lite / LiteRT.js 2.5.3** へ推論ランタイムを変更した版です。TensorFlow.js版ではありません。検証済み1.0.3.15の処理を引き継ぎ、AI自動操作、Gemini API、Pi、逐次反映、欠落IDの再依頼、言語設定、カスタム指示を利用できます。

Piの導入・接続は [PI.md](PI.md)、モデルとライセンスは [MODEL.md](MODEL.md) と [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)、変更履歴は [CHANGELOG.md](CHANGELOG.md) を参照してください。

## インストール・更新

[最新リリース](https://github.com/okinisu/manga-translator-extension/releases/latest) の添付ファイル **manga-translator-2.0.0.zip** をダウンロードしてください。GitHubが自動生成する「Source code」のZIPではなく、拡張機能用ZIPを使います。

1. ZIPを専用フォルダへ展開し、Chromeの `chrome://extensions` でデベロッパーモードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` があるフォルダを選びます。
3. 通常版との二重動作を避けるため通常版を無効にします。更新後は拡張機能と漫画ページを再読み込みしてください。
4. AI・言語・接続設定を確認し、画像準備または自動翻訳を開始します。Piの導入・ブリッジ起動は[PI.md](PI.md)を参照してください。

別フォルダから読み込むと拡張機能IDが変わり、設定を入れ直す場合があります。既存フォルダへの更新なら設定を維持できます。

## 推論設定

- **自動**：AMD RDNA3では特徴抽出FP16＋検出後段FP32。NVIDIAと未検証GPUは全体FP32です。
- **FP32（精度優先）**：全体FP32を使います。
- **部分FP16**：検証済みAMD RDNA3向け。NVIDIAでは有効にしていません。
- **全体FP16（速度優先）**：shader-f16対応の検証済みAMD RDNA3 / NVIDIA Lovelaceで、全体をFP16で実行します。非対応GPUはFP32へ戻ります。
- **CPUのみ**：全体FP32モデルをLiteRT WASMで実行します。通常ONNX版のINT8とは異なります。

FP16失敗時はFP32で再試行します。自動モードではGPU失敗時にCPUへ戻ります。GPUの選択はブラウザが決めます。Graph Captureはこの版では使いません。

## 検証済みの最適化

NVIDIA Lovelaceでは「全体FP16（AMD／NVIDIA・速度優先）」で、FP16の作業用キャッシュ・積和演算・入力変数の最適化を利用できます。このモードに特殊なsubgroup-matrix／Tensor Core機能は不要です。Tensor Coreを使う推論オプションは引き続き実験扱いです。

RTX 4060 Laptop / Linux Vulkan / Chrome beta 157、640×640・バッチ1・ウォームアップ後、4画像・2回の交互計測（各版96回）で、全体FP16の推論応答中央値は旧1.0.3.14の **36.03ms → 29.21ms（約18.9%短縮）** でした。2.0.0の推論処理は、この測定を行った1.0.3.15と同一です。

32画像のONNX FP32との比較では検出数・クラスが一致し、最大のボックス辺の位置差は **0.713px** でした。これは参照モデルとの一致度で、人手の正解に対する検出精度ではありません。応答時間にはGPU正規化・CPU補助・出力読み戻しを含み、漫画全体の処理時間や公式TensorRTのFPSとは直接比較できません。詳細は [TENSOR-RESULTS.json](TENSOR-RESULTS.json) を参照してください。

## 入力処理とモデル

白背景で組み立てた不透明・640×640の検出画像は、検証済みGPUで直接RGB正規化します。CPU読み戻しとFloat32入力の再転送を省きます。透明度不明・他の寸法・未対応環境・転送失敗時は従来のCPU前処理です。前処理のGPU実行分は推論時間に含まれます。

モデルの重みと入力サイズは変えていません。FP16では対象の畳み込み積和も半精度化します。LiteRTのWinogradシェーダーの型を補正し、コンパイル・GPU検証エラーを監視します。部分FP16は2モデルをGPU上で接続し、CPU FP32では全体モデルと4入力の生出力が完全一致しています。全体FP32のフォールバックモデルも同梱するため配布サイズは約323MBです。

## 測定・注意事項

メニューの「TFLite推論ベンチマーク」は、白背景の入力を使い2回ウォームアップ後5回測定し、診断JSONを保存できます。画像をAIへ送信しません。

試験版です。OCR・翻訳の誤りが起こり得ます。画像の権利とAIサービスの利用条件を確認し、利用は自己責任でお願いします。画像・接続キー・アカウント情報は配布物に含みません。[プライバシー](PRIVACY.md)、[モデル](MODEL.md)、[第三者ライセンス](THIRD_PARTY_NOTICES.md)、[変更履歴](CHANGELOG.md)も参照してください。
